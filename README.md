# Neon Dodge — solo Godot project (micro1 qualification build 1)

A complete 2D arcade dodger built in Godot 4 with GDScript:
- Player movement (touch + keyboard), screen-bounds clamping
- Timed enemy spawner with increasing difficulty
- Collision detection, lives, score, game over + restart
- HUD (score/lives), start screen, pause

Built by Opeyemi Peter Adeshina with AI assistance; published for portfolio verification.
